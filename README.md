# Chatty Chart Desk

Title: AI-Powered Workplace Productivity Application

Role: Act as an expert web developer and AI specialist.

Objective: Build one AI-powered website to improve workplace productivity and save time.

Context: Companies need an easier way to write emails, summarize meetings, and analyze data.

Requirements:

Smart Email Generator: Create professional emails quickly.

Meeting Notes Summarizer: Summarize meetings, decisions, and action items.

AI Chart Bot: Turn data into charts and graphs.

Dashboard: Combine all three tools in one user-friendly, secure website.

Outcome: Create a modern, reliable application that automates tasks, improves communication, and helps employees work more efficiently.
